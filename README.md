# Приключения с часами (Clock Adventure)

Обучающая браузерная игра для детей 7–8 лет на тему «Учимся определять время по часам». 

Игра представляет собой приключение, где ребёнок проходит различные уровни, выполняя задания на определение и установку времени на аналоговых часах. Успешное выполнение заданий вознаграждается звёздами. Прогресс сохраняется автоматически.

## Особенности
- **32 интерактивных задания**: Определение времени, установка стрелок, задачи на продолжительность.
- **Интерактивные аналоговые часы**: Красивый SVG-циферблат с возможностью перетаскивания часовой и минутной стрелок.
- **Система прогресса**: Получение от 1 до 3 звёзд в зависимости от количества ошибок. Прогресс сохраняется в браузере (через `localStorage`).
- **Подсказки и анимации**: Помощь при затруднениях и визуальная обратная связь.
- **Адаптивный дизайн**: Работает на смартфонах, планшетах и ПК.

## Как запустить игру
Для запуска игры не требуется сервер. Достаточно открыть файл `index.html` в любом современном браузере.
Проект готов для публикации на **GitHub Pages**:
1. Загрузите код в репозиторий GitHub.
2. Перейдите в Settings -> Pages.
3. Выберите ветку `main` или `gh-pages` как источник (Source).
4. Игра будет доступна по ссылке вида `https://<ваше-имя>.github.io/clock-adventure`.

## Структура проекта
- `index.html` — Главный файл приложения.
- `css/style.css` — Стили (адаптивность, анимации).
- `js/clock.js` — Логика интерактивных SVG-часов.
- `js/levels.js` — База данных уровней и заданий.
- `js/app.js` — Основная логика игры (переключение экранов, прогресс, проверка ответов).
- `test.html` и `js/tests.js` — Инструменты для тестирования.

## Запуск тестов
Откройте файл `test.html` в браузере и проверьте Консоль разработчика (F12 -> Console) на наличие сообщения об успешном прохождении тестов.
Или запустите тесты в терминале через Node.js:
```bash
node -e "
const fs = require('fs');
const vm = require('vm');
const dom = {
  createElementNS: () => ({ setAttribute: () => {}, style: {}, appendChild: () => {}, addEventListener: () => {} }),
  createElement: () => ({ setAttribute: () => {}, style: {}, appendChild: () => {}, addEventListener: () => {}, classList: { add: ()=>{}, remove: ()=>{} } }),
  getElementById: (id) => ({ innerHTML: '', appendChild: () => {}, classList: { add: ()=>{}, remove: ()=>{} } })
};
const context = vm.createContext({ document: dom, window: { addEventListener: () => {}, innerWidth: 800 }, console: console });
vm.runInContext(fs.readFileSync('js/levels.js', 'utf8'), context);

vm.runInContext(fs.readFileSync('js/tests.js', 'utf8'), context);
vm.runInContext('runTests()', context);
"
```
